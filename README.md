# Adult Combined Screening Report

This is a standalone static web app for an adult-focused screening report across ADHD, autism spectrum traits, AuDHD co-occurrence, legacy Asperger's-style profile, OCD, cognitive disengagement syndrome, anxiety, and differential factors.

Open `index.html` in a browser. No build step or server is required.

The generated report can be exported directly as a PDF or printed from the browser.

Important clinical framing:

- The app does not diagnose. It produces screening-match percentages and clinician discussion notes.
- CDS is included as a research construct, not a DSM diagnosis.
- Asperger's disorder is no longer a separate DSM diagnosis; the app frames it as a legacy profile under autism spectrum discussion.
- Answers are stored only in the browser's local storage.
